# 作品集 · 一页说明

**项目**：CRM 销售提效 Agent（面向批量中小广告主的 AI 原生智能体）
**代码**：`hello-agents/crm-sales-agent`（本地可运行，无需 API Key 也能演示）
**一句话**：让销售用一句话拿到「这个客户值不值得投入、下一步做什么、开口怎么说」。

---

## 我做了什么

| 模块 | 我的实现 | 解决的业务问题 |
|---|---|---|
| 意图路由 | LangGraph 条件边 + 关键词规则 + 模型兜底 | 一句话可能是画像/商机/分析/方法论，先分流再执行 |
| 客户画像 | 聚合档案、计划、月度指标、跟进记录，产出"一句话判断 + 风险 + 建议" | 新人不用翻 4 张表也能在 30 秒内看懂一个客户 |
| 商机评分 | 5 条流失信号 + 6 类商机规则，业务优先级排序（保命 → 续约 → 增量） | 该挽留还是该增投，有统一口径，可追溯到具体指标 |
| 商机表达 | 检索 SOP/案例 → 动作三步 + 开口话术 + 预估增量 + 引用来源 | 建议能直接执行，不是"加强运营"这种废话 |
| 经营分析 | Text-to-SQL + 白名单校验 + 只读连接 + 归因提示 | 不写 SQL 也能出数，且不会因为一句"删掉这张表"而炸库 |
| 反思自检 | 检查数字、引用、信息量，不通过回退重跑一次 | 避免出现没有数据支撑的"结论" |
| 评估 | 37 条用例，四指标自动跑分 | 用数字说明它答得对，而不是"看起来不错" |

## 技术栈

Python 3.13 · LangGraph（StateGraph + MemorySaver）· OpenAI 兼容接口 · SQLite · FastAPI · 自实现中文 BM25 · 单文件前端

## 结果

- 意图准确率 **100%**、关键事实命中率 **97.3%**、引用覆盖率 **100%**、自检通过率 **100%**（37 条用例，离线模式可复现）
- 离线全链路平均延迟 **约 8 ms**；接入大模型后表达质量提升，延迟上升到秒级
- 自建 42 个广告主的模拟数据集（表间强一致）+ 8 篇策略/案例知识库

## 边界（我会主动说清楚的部分）

- 数据是模拟的，没有真实客户信息，也没有真实投放效果验证；
- 自定义时间窗口（"近 45 天"）答不出——库里只有近 30 天和月度两套口径，这条失败用例保留在评估集里；
- 比较类只覆盖两/三个客户的单指标对比和单客户月度环比，"和行业均值比"这类没有模板；
- 参考了 Datawhale Hello-Agents 的方法论（ReAct / Reflection / 记忆与检索），业务代码为独立实现。

## 30 秒讲法（面试开场用）

> 我做了一个给中小广告主销售用的 Agent。销售手上几百个客户，最费时间的是判断"这个客户现在该加量、该续费还是该挽留"。我把这件事拆成三层：规则引擎负责算（流失信号、商机分数，可追溯），知识库负责"怎么说"（SOP 和案例，带引用），LangGraph 负责编排（路由 → 三个子 Agent → 反思自检）。我给它写了 37 条评估用例，意图准确率 100%，唯一的失败是"自定义时间窗口"——我把它留在评估集里，没有删掉，也没有改成 100%。
